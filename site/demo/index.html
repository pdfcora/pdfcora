This demo needs to be served over http://

You have opened it from the filesystem. Browsers refuse to load ES modules or fetch files from file://, so the engine cannot start. Serve the folder and open the address it prints:

cd site && python3 -m http.server 8000
# then open http://localhost:8000/demo/
